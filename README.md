# TP de programmation objet en Java

Ce dépôt rassemble les travaux pratiques et exercices Java réalisés dans le
cadre de la programmation objet.

## Contenu

- `tp1/` : exercices du TP1
- `TP2_LIN_Jacques_programmation_objet/` : exercices du TP2
- `TP3_LIN_Jacques_programmation_objet/` : exercices du TP3
- `TP4_LIN_Jacques_programmation_objet/` : exercices du TP4
- `exercice/` et `Nouveau dossier/` : autres exercices Java présents dans le dossier d'origine

Les fichiers compilés (`.class`), les archives (`.zip`) et les paramètres
locaux de Visual Studio Code ne sont pas inclus.
